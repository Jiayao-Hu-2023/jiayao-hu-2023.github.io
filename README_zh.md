# 答案之书

一个神秘的网络应用，为你的问题提供答案。静心默念你的问题，让宇宙为你揭示答案。

[中文版本](README_zh.md) | [English Version](README.md)

## 功能特点

- 📖 经典的"答案之书"体验
- 🌐 双语支持（中文和英文）
- ✨ 美观直观的界面
- 💫 来自宇宙的随机智慧

## 使用方法

1. 在浏览器中打开 `index.html`
2. 在心中默念你的问题
3. 在输入框中写下你的问题
4. 点击获取答案之书给你的答案

## 示例问题

- 我应该换一份工作吗？
- 他/她在想我吗？
- 现在开始来得及吗？
- 该不该主动一点？
